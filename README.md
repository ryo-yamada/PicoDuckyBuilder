# PicoDuckyBuilder
A tool to automate the process of converting a Raspberry Pi Pico into a USB Rubber Ducky.

- Major credit to [@dbisu](https://github.com/dbisu) on GitHub for maintaining the main repository for converting an RPi Pico into a USB Rubber Ducky.  
- Credit to [@steveiliop56](https://github.com/steveiliop56) on GitHub for inspiring me to make this tool.

## Use guide
1. Download the project as a zip folder.
2. Extract the zip anywhere.
3. Open a terminal and cd into the folder.
4. Run `$ py runthis.py` or `$ python3 runthis.py` or `$ python runthis.py`.
5. Follow the instructions.

## Post install
- Refer to [dbisu/pico-ducky -> README.md](https://github.com/dbisu/pico-ducky) for additional info on how to use your new PicoDucky.
- Refer to [hak5 DuckyScript documentation](https://docs.hak5.org/hak5-usb-rubber-ducky/duckyscript-quick-reference/) for additional info on how to edit your payload.

# PicoDuckyBuilder
A tool to automate the process of converting a Raspberry Pi Pico into a USB Rubber Ducky.

- Credit to [@dbisu](https://github.com/dbisu) for maintaining the [main repository](https://github.com/dbisu/pico-ducky) for converting an RPi Pico into a USB Rubber Ducky.
- Credit to [@steveiliop56](https://github.com/steveiliop56) for inspiring me to make this tool.

## Use guide
1. Download the project as a zip folder.
2. Extract the zip anywhere.
3. Open a terminal and cd into the folder.
4. Install the required libs with `pip install -r requirements.txt`
5. Run `$ py runthis.py` or `$ python3 runthis.py` or `$ python runthis.py`.
6. Follow the instructions.

## Post install
- Refer to [dbisu/pico-ducky -> README.md](https://github.com/dbisu/pico-ducky) for additional info on how to use your new PicoDucky.
- Refer to [hak5 DuckyScript documentation](https://documentation.hak5.org/hak5-usb-rubber-ducky/duckyscript-tm-quick-reference) for additional info on how to edit your payload.
